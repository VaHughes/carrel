# A quiet place to read

Carrel keeps your Markdown readable in the terminal. Open a document,
follow a link, or find a phrase — your place stays put when the window changes.

## A small reading list

| Document | What is inside | Status |
| :--- | :--- | :--- |
| Getting started | Your first five minutes | Ready to read |
| Field notes | Ideas worth keeping | In progress |
| Release checklist | The next small steps | Ready to read |

## Start with what you have

```sh
carrel                  # browse nearby Markdown
carrel field-notes.md    # read one document
carrel --latest         # open the newest file
```
