# Code of Conduct

Carrel follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

The short form: be kind, argue about code and not about people, and remember that a small project
lives or dies by whether strangers enjoy showing up. Harassment, personal attacks, and sustained
disruption are not welcome, and reports can be made privately to the maintainer through GitHub.

Enforcement follows the Covenant's guidelines: correction, warning, temporary ban, permanent ban —
in that order, with judgment.
